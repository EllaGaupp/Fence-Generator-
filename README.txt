Challenge Features:
- Create a procedural fence with the following parameters
    - allow user to adjust amount of fence panels
    - allow user to adjust the width of the fence panels
    - allow user to adjust the spaceing between fence panels
    - allow user to adjust the height of fence panels
    - allow user to enable random height variation
    - allow user to enable random missing panels
- Destroy old fence when a new one is generated to avoid clutter
- Allow the Fence Generator UI to stay up when clicking off of it
